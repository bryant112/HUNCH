HUNCH launcher pack

1. Extract this folder under C:\dev\HUNCH-launcher (or another non-OneDrive path).
2. Subscribe/install CBA_A3 (Workshop 450814997).
3. Double-click Launch-HUNCH.cmd.
4. Arma opens the HUNCH test mission with CBA and HUNCH loaded. Press Preview in the editor to start the range.

Launch-HUNCH-With-Shot-Signal.cmd adds installed Shot Signal (Workshop 3426116212) independently. It does not change or coordinate either addon.

The pack refuses to start over an active Arma or map-tools process and uses a pack-local Profiles folder. It does not copy files into the Arma install, alter existing profiles, or modify maps.

HUNCH is a packaged implementation candidate. Read docs/STATUS.md and docs/ACCEPTANCE.md before treating attended visual, event, or performance acceptance as complete.
