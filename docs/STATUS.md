# Implementation evidence

## Implemented

- Standalone CBA addon and stock VR test mission, isolated under this repository.
- Native incoming evidence with bounded original-shot records and duplicate protection.
- Noticeability/confidence model, sparse correlated episodes, amber scene/border rendering, flash approximation, and 30m close-visible dismissal.
- Settings/reset/keybind, lifecycle cleanup, local context-provider contract, diagnostics, and benchmark capture/analyzer.
- Reproducible texture generation, configuration compilation, PBO build and byte-level readback.
- Packaged double-click launcher pack with Steam-library discovery, CBA dependency check, optional Shot Signal load, active-session guard, and pack-local profile.

## Verified without launching Arma

See `build/validation/results.json` for source hashes and current totals. The check runner parses all production/test-mission SQF, runs production scoring/layout and selected state behavior in SQF-VM, validates three Arma configuration files with CfgConvert, and checks scope/renderer source contracts.

The state harness substitutes an empty UI sentinel for the VM's missing display type and stubs diagnostics because its getOrDefault operator is unimplemented. It does not stub the production queue/deduplication/emission logic under test. UI controls, native event delivery, visibility, and engine performance are not exercised by that harness.

Build output includes `manifest.json` with artifact hashes and entry counts. Packaged files are compared with staged source/generated bytes.

Current automated totals: 24 SQF files parsed; 23 production-math/layout assertions; 12 queue/emission/reset assertions; 6 Python packaging/evidence-tool tests; 3 configuration checks. PowerShell scripts also parsed successfully. The launcher's active-session refusal was exercised successfully while the original Arma session remained running. Release ZIP CRCs passed.

## Conservative boundaries

- Exact Shot Signal event internals are unavailable (installed PBO is obfuscated); no integration or coordination exists.
- Native event coverage is not universal. Null/expired projectile context and long-flight reports fail closed.
- Visual flash confirmation is an approximation. Suppressed/unknown effects omit dots.
- Hearing providers are an extension point, not a claim of a tested ACE hearing integration.
- Large amber spots have not yet passed terrain/background/optics visibility review.

Status: **packaged implementation candidate, not an attended-validated release**.
